漫画阅读器 v1.0.0
==================================================

一个只在你自己电脑上跑的本地漫画阅读器。
不联网、不登录、不上传任何东西。


一、怎么装
--------------------------------------------------

方式 A：安装到系统（推荐，有桌面图标）

  1. 双击「点我安装.bat」
  2. 等它跑完，桌面会出现「漫画阅读器」
  3. 以后从桌面双击启动即可

  安装位置：%LOCALAPPDATA%\Programs\漫画阅读器
  想卸载：设置 → 应用 → 应用和功能 → 找「漫画阅读器」→ 卸载


方式 B：不带安装，直接用

  直接双击「漫画阅读器.exe」就能跑。
  整个文件夹可以放 U 盘、放别的盘，随时拷走。


二、第一次打开
--------------------------------------------------

程序会弹出「选择漫画文件夹」，选中你放漫画的那个文件夹。

  · 你的漫画不会被复制、不会被移动、不会被改名
  · 程序只读取里面的图片
  · 选好之后，书架会记住这个目录

想换文件夹：点右上角文件夹图标，或按 Ctrl+O
重新扫描：  点右上角刷新图标，或按 Ctrl+R


三、书架怎么浏览（一层一层进）
--------------------------------------------------

  1. 打开后看到的是根目录下的文件夹
  2. 双击文件夹进入，看到里面的内容
  3. 再双击进入下一层，直到看到漫画封面

  顶部有面包屑：书架 › Pixiv › 成田大进
  点任意一级可以直接跳回去。

  返回上一层：左上角返回箭头 / Alt+← / Backspace


  自动展开：如果某一层里的子文件夹全是漫画，
  会直接显示封面，不用再点一次。
  比如进入「成田大进」，直接看到 89 本封面。


四、搜索
--------------------------------------------------

  点顶栏放大镜，或按 Ctrl+F

  · 输入即搜，支持搜书名、作者名、日期、路径
  · 结果显示为「文件夹在前、书在后」
  · 双击结果里的文件夹会进入那个目录
  · 点「退出搜索」回到你搜索前的位置

  注意：搜索用的是上次扫描的缓存。
  如果你刚往硬盘里加了新漫画，先点刷新再搜。


五、四种阅读方式
--------------------------------------------------

  单页     一张一张翻，点左边/右边翻页
  跨页     两页并排，适合横屏
  条漫     上下连续滚动，适合韩漫
  长卷     左右横排、图片之间零间隙
           ← 第一张在最左边，往右依次铺开
                滚轮向下 = 画面往左走 = 往后读
                点画面中间 = 工具栏和缩略图带一起出现
                再点一次 = 一起收起
                缩略图带就在进度条上方，点任意一张直接跳过去

  切换方式：底部工具栏的四个按钮


六、默认阅读方式（每本新书用什么方式打开）
--------------------------------------------------

  书架右上角「默认阅读方式」按钮（排序按钮右边）

  · 可设：单页 / 跨页 / 条漫 / 长卷
  · 还能设阅读方向：从左往右 / 从右往左（日漫）
  · 只影响「还没读过的书」
  · 已经读过的书会接着上次的方式继续，不会被打断


七、自定义封面
--------------------------------------------------

  在书架上右键任意一本书 → 「设置封面…」→ 选一张图片

  · 只记录图片路径，不复制、不移动你的文件
  · 支持 jpg / png / webp / gif / bmp / avif
  · 想恢复原样：再右键 → 「恢复默认封面」
  · 如果自定义的图片被你删了，会自动退回默认封面


八、快捷键
--------------------------------------------------

  滚轮            翻页 / 长卷模式左右移动
  Ctrl+F          搜索全书架
  ← →             翻页
  空格            显示 / 隐藏工具栏
  Esc             返回书架
  F11             全屏
  Ctrl+O          换漫画文件夹
  Ctrl+R          重新扫描（书架上）
  Alt+←           返回上一层（书架上）
  双击            放大 2.4 倍（单页/跨页模式）
  右键书架卡片    重命名 / 设置封面 / 打开文件夹 / 重置进度


九、阅读进度存在哪
--------------------------------------------------

  %APPDATA%\漫画阅读器\progress.json

  这是个普通文本文件，记录「每本书看到第几页」。
  把它拷走就等于备份了进度，换电脑时拷回来即可。

  同目录下还有：
    books.json      书架缓存（哪本书、多少页）
    covers 相关     自定义封面的路径记录（在 progress.json 里）

  点书架右上角的数据库图标可以直接打开这个文件夹。


十、支持的格式
--------------------------------------------------

  图片：jpg / jpeg / jfif / png / webp / gif / bmp / avif
  压缩包：zip / cbz
  文档：pdf

  · webp 和 gif 现在也能正常显示封面了
  · gif 动图在阅读页面会真的动
  · 封面缩略图是静态的（只取第一帧）


十一、性能说明
--------------------------------------------------

  打开软件：只读当前一层目录，毫秒级
  进入文件夹：读一层，通常 10~40 毫秒
  全量扫描：约 500 本 / 1 秒（只在点刷新时发生）
  封面加载：滚动到哪就加载哪，不一次全读
  长卷模式：按需加载，几千页的书也只同时保留几张图
  PDF/压缩包：首次打开要解析，之后有缓存


十二、常见问题
--------------------------------------------------

  Q: 封面显示灰色的书本图标？
  A: 那本书所在目录里没有可识别的图片，
     或者自定义封面指向的文件已被删除。

  Q: 往硬盘里加了新漫画，书架没显示？
  A: 按 Ctrl+R 或点右上角刷新。软件不会自动监控文件变化。

  Q: 读英文名作品搜索不到？
  A: 大小写不敏感，中英文都能搜。
     但如果作品是刚加的，需要先刷新扫描一遍。

  Q: 某本书打不开？
  A: 检查那个文件夹里是不是真的有图片文件。

  Q: 会不会偷偷联网？
  A: 不会。程序内置了请求拦截，任何外网地址都会被拒。
     你可以拔掉网线试，功能完全正常。
